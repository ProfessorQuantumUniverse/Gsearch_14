Eine minimalistische Android-App zum schnellen Suchen – mit Suchverlauf und cleanem Material-Design.

## ✨ Features

- ⚡ Schnelle Suche direkt beim Tippen
- 🕘 **Suchverlauf** mit eigener Liste
- 🎨 Modernes Material-Design
- 🪶 Leichtgewichtig & schnell

## 🛠️ Tech-Stack

`Kotlin` · `Android SDK` · `Gradle`

## 🚀 Build

```bash
# In Android Studio öffnen und ausführen, oder:
./gradlew assembleDebug
```
